# Spec: Fix medium — upgrade socket.io to ≥ 4.6.2 and socket.io-parser to ≥ 4.2.3

**Issue**: #57
**Date**: 2026-08-01 (dev-rework)

## Approach

`socket.io` and `socket.io-parser` are transitive dependencies of `webpack-dev-server` (used by the Angular CLI dev server for live-reload/HMR). They are not direct runtime dependencies.

Two medium-severity Dependabot alerts are open:
- `socket.io` in range `>=3.0.0 <4.6.2`
- `socket.io-parser` in range `>=4.0.4 <4.2.3`

The `package.json` overrides block already contains the required entries:
```json
"socket.io": ">=4.6.2",
"socket.io-parser": ">=4.2.3"
```

The original implementation added the overrides correctly. This dev-rework pass runs `npm audit fix` to fully regenerate `package-lock.json` with all pending security fixes applied (several unrelated vulns were resolved by `npm audit fix`, ensuring the lock file is coherent and current), then confirms:

1. `npm ls socket.io socket.io-parser` → socket.io@4.8.3, socket.io-parser@4.2.7 (both satisfy overrides)
2. `npm audit` → no advisories for socket.io or socket.io-parser
3. `npm run build` → exits 0

No application source files (`src/`) are touched.

## Files to Change

- `package-lock.json`: Regenerated by `npm audit fix` / `npm install` to reflect the overrides and any `npm audit fix`-resolvable secondary fixes.

## Files NOT to Change

- `package.json`: Already has the correct overrides — no changes required.
- `src/**/*`: Out of scope — no application source changes required.
- Any Angular component, service, or configuration files: out of scope.

## Risks / Assumptions

- `socket.io` ≥ 4.6.2 is compatible with the version of `webpack-dev-server` resolved by `@angular-devkit/build-angular@^22.1.2`.
- The `socket.io-parser` ≥ 4.2.3 override also satisfies the critical-severity alert range (`>=4.0.0 <4.0.5`) from issue #51.
- Remaining moderate advisories in `npm audit` output are for packages outside this story's scope (uuid/sockjs/webpack-dev-server, @hono/node-server, ajv).
- `npm run build` exits 0 — confirmed.
