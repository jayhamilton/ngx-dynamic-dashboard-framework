## Number Card

A compact KPI tile for highlighting a single important number.

### Configuration

- **Title / Subtitle** — shown in the card header.
- **Card Color / Band Color / Text Color** — hex color values (e.g. `#3f51b5`) controlling the tile's background, accent band, and text color.

### Chart Data

Edit **Chart Data (JSON)** to set the value(s) shown on the tile — see the placeholder JSON in the editor for the expected shape before replacing it with your own data.
