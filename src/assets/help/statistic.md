## Statistic

Displays a single metric with an optional icon, trend indicator, and caption — a lightweight alternative to the Number Card gadget.

### Configuration

- **Title / Subtitle** — shown in the card header.
- **Value** — the headline number or text (e.g. `1,204`, `98%`).
- **Label** — a short description under the value (e.g. "Active Users").
- **Change** — a signed value like `+2.4%` or `-3`; its sign drives the up/down trend arrow and color automatically. Non-numeric text (e.g. "n/a") shows as-is with no arrow.
- **Caption** — smaller supporting text below everything else.
- **Icon** — pick an icon shown alongside the value.
- **Theme** — the tile's color theme (brand, success, warning, info, purple, teal, or neutral gray).
- **Show Icon** — toggle whether the icon renders at all.
